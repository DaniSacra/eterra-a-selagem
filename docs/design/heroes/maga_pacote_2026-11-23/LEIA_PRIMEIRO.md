# Maga de Eterra | Pacote de Handoff v2

Este pacote reúne a proposta atualizada da **Maga** para *Crônicas de Eterra: A Selagem*.

## O que mudou nesta versão

A direção visual foi **corrigida** com base na referência reenviada pelo usuário.
A partir desta versão, a leitura correta é:

- a Maga deve ter **traços asiáticos/leste-asiáticos**, tomando como base a foto em `artes/00_modelo_facial_referencia.png`
- a personagem aprovada é a arte em `artes/01_maga_aprovada_principal.png`
- a identidade principal da personagem é **Maga de Fogo**
- manter o **cajado/bastão de duas pontas** com fogo/luz nas extremidades
- manter o traje aprovado: **capa marfim** por cima de roupas em **azul profundo**, com linguagem dark fantasy painterly, coerente com Eterra

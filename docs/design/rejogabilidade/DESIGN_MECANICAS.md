# Visão sistêmica
| Sistema | Persistência | Função |
|---|---|---|
| Maestria | permanente | abrir progressão do Guerreiro |
| Dons + Devoção | configuração pré-run | especialização com pré-requisitos |
| Forja Emeth | permanente | aprimorar a espada única |
| Bênçãos + Elos | por run | poderes e sinergias imprevisíveis |
| Salmos | por run | transformação excepcional |
| Encantos/Lapidação | por run | modificar ataques e Ômegas |
| Ouro | por run | lojas |
| Materiais | permanente | craft e desbloqueios |
| Juramentos | pré-run | risco/recompensa |

**Cuidado:** a spec do Guerreiro já documenta Dons em quatro ramos Combo, Fúria, Emeth e Magia, Maestria e capacidade de Devoção; o estudo `hades2_sistemas.md` já propõe `WeaponUpgrade` e Lapidação. Não duplicar.

## Dons sem tarô
Apresentação como **Livro dos Dons**, manuscrito de Akh com nós e conexões. A inspiração bíblica é a noção de vocação, dons e perseverança, sem versículos literais ou Deus como NPC. Fragmentos de Memória só entram se não duplicarem Maestria/Devoção.

## Exemplos de builds
- Combo longo + Encanto Lâmina Tríplice + bênção de finalizador.
- Corte Veloz + Encanto Retorno do Corte + bênção de esquiva ofensiva.
- Ômegas frequentes + bênção de Magia + Salmo transformador.

A spec já recomenda **Fúria sem barra nova**: cargas breves, sem aumentar HUD.
